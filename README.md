# Virabraking — Controle de Manutenção Veicular
O **Virabraking** é um aplicativo Android nativo desenvolvido para ajudar proprietários de veículos a acompanharem o histórico de manutenções, trocas de óleo, revisões periódicas e despesas gerais do seu carro ou moto.

O objetivo do projeto é substituir a caderneta de papel no porta-luvas por uma interface simples, rápida e que funcione offline.

## Funcionalidades

- **Cadastro de Veículos:** Gerencie múltiplos veículos (carro, moto, etc.).
- **Registro de Manutenções:**
  - Troca de óleo e filtros.
  - Revisões preventivas e corretivas.
  - Substituição de peças (pneus, freios, correia, etc.).
  - Gastos com combustível e documentação.
- **Histórico e Detalhes:** Armazene data, quilometragem no momento do serviço, valor gasto, oficina e observações.
- **Alertas e Lembretes:** (Em desenvolvimento) Notificações baseadas em quilometragem ou data para a próxima revisão/troca de óleo.
- **Relatório de Gastos:** Visualização do custo total acumulado por veículo ou categoria.

## Tecnologias Utilizadas

**Linguagem:** Kotlin  
**IDE:** Android Studio  
**Componentes de UI:** Jetpack Compose (ou XML Layouts, ajuste conforme seu uso)  

## Como Executar o Projeto

Pré-requisitos:

- **Android Studio** instalado (versão Giraffe ou superior recomendada).  
- SDK Android configurado (API mínima recomendada: 24 / Android 7.0).  
- Um emulador Android ou um dispositivo físico com a depuração USB ativada.
